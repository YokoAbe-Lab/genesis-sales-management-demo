# Genesis Excel・VBA静的解析

## 解決したい課題

仕様書が十分にないExcelでは、どのシート・数式・VBA処理が関係しているかを調べる作業が必要になります。Genesisは保存済みファイルから構造とソースを読み取り、調査・保守・引継ぎに使う材料を整理する自主制作ツールです。実業務への導入効果や削減時間は、この公開デモでは測定していません。

## 実装で確認できること

| 観点 | 実装・証拠 |
|---|---|
| 原本保護 | コピー作成とSHA-256照合。原本維持を公開試験で確認 |
| Excel構造の解析 | シート・数式等の構造と保存機能を抽出。`app/excel_static.py`、`app/excel_features.py` |
| VBAの読取り | Javaの読取り部品とPythonでモジュール・プロシージャ・関係を整理。`app/java/LocalVbaReader.java` |
| 結果の確認 | 一覧・検索・詳細・関係の画面。`app/static/excel.js` |
| 出力と追跡 | 解析結果を保存し報告出力。`app/excel_export.py` |
| 異常系への対応 | 入力サイズ等の制限、破損入力の拒否、取得状態の区別 |

抽出した関係は静的な調査材料です。実行時の全経路や業務上の正しさを保証するものではありません。

## 架空教材で試す

1. [READMEの起動手順](../README.md#起動方法)で起動します。
2. `http://127.0.0.1:8773/excel` を開きます。
3. 「01 解析する」で架空の見本を選んで解析します。実務ファイルは不要です。
4. 「02 結果・関係」で一覧から対象を選び、詳細と関係を確認します。原本とコピーのハッシュ表示も確認できます。
5. 「03 報告書・VBA保存」で出力を確認します。

教材のVBAは抽出用であり、Excel起動やマクロ実行は行いません。`.xlsb` 教材は最小コンテナーの読取り試験用で、通常のExcel編集用途ではありません。

## 検証の範囲

公開用コピーでは、販売閲覧・Web・Excel解析を合わせて **57件成功、0件失敗**でした。これはExcelだけの57試験という意味ではありません。[各項目の期待値と実測値](test-results.json)を公開しています。合成教材の解析、出力、入力ハッシュ維持、破損入力の拒否を含みます。

元のv07資料には40試験・機能9項目・AI連携1回の記録がありますが、この公開版で再実行した試験とは区別します。今回の公開確認では実AIを呼び出していません。画面に残る旧試験・AI連携の説明も、今回の再実行結果ではありません。

他PCでの新規構築、実務Excel全般の互換性、VBA実行、実AIによる全工程、Access解析への統合は未確認です。

## Access解析との関係

Accessのテーブル・SQL・VBAを調べるGenesis Access解析は別の製品です。今回確認した取込手順は、既存Access本体のモジュール・テーブルを前提としており、取込用コードだけで独立起動できる構成ではありません。本体や過去の解析結果について公開可否を確定できていないため、このリポジトリには追加していません。

同梱のAccess販売管理は架空データを読むための機能です。Access解析が統合済みであることを意味しません。

## 公開対象の選定

就職用の主な作品として、説明できる用途、確認済みの動作、コードと教材を同時に提示できるExcel解析を選びました。既存公開物に含まれる実装を重複して別リポジトリにせず、この紹介から案内しています。今回の整備は説明書のみで、製品コード・元ファイルは変更していません。
